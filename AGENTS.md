# Local Rules

- Do not describe a coding task as completed, validated, or a working proof of concept unless the code compiles successfully first.
- If `build` or `cargo check` fails, treat the work as incomplete even if the implementation draft looks reasonable.
- Do not talk about tests until the project compiles.
- For implementation tasks, the minimum bar is: compile first, then test, then claim functionality.
- Codex 生成的操作步骤记录、排障备忘、实现日志等面向本项目内部/当前用户的文档默认使用中文；`README.md` 等面向外部读者或已有语言风格明确的文档保持原有语言和风格。
